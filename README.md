# RBK Mihon Extensions

Repositorio personal de extensiones para **Mihon**.

Las extensiones incluidas en este proyecto son desarrolladas y mantenidas de forma independiente.

## 📦 Extensiones

Las extensiones disponibles se encuentran organizadas por idioma dentro de:

```text
src/
└── es/
```

Actualmente el repositorio está enfocado principalmente en fuentes en español.

## 📲 Instalación

Las extensiones se distribuyen mediante un repositorio compatible con Mihon.

Para utilizarlas es necesario agregar el repositorio de extensiones correspondiente desde la configuración de Mihon.

## 🔄 Actualizaciones

Las extensiones pueden actualizarse independientemente.

Cuando una nueva versión esté disponible, Mihon podrá detectarla desde el repositorio de extensiones.

## 🛠️ Desarrollo

Este proyecto utiliza la estructura de extensiones compatible con Mihon.

Cada extensión se encuentra en su propio módulo:

```text
src/es/nombreextension/
├── build.gradle
├── res/
└── src/
```

## ⚠️ Aviso

Este proyecto no está afiliado con Mihon ni con los sitios utilizados como fuentes.

Las extensiones únicamente facilitan el acceso al contenido proporcionado públicamente por sus respectivas fuentes.

Los nombres, logotipos y contenido pertenecen a sus respectivos propietarios.
